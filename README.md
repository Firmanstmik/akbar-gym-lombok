# Akbar Gym — Premium Landing Prototype

Phase 1 client-facing homepage prototype for **Akbar Gym** (South Lombok).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Lucide icons
- UI/UX Pro Max design system (`design-system/akbar-gym/`)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Docs

- `docs/AKBAR-GYM-CONTENT-SOURCES.md` — research & media attribution
- `docs/AKBAR-GYM-CONTENT-TODO.md` — owner confirmation checklist (internal)
- `public/images/akbar-gym/MANIFEST.md` — media map
