## Brand observations from real media

- Logo wordmark style: lowercase **akbar** (orange) + **Gym** (white)
- Brand orange ~`#E86324`
- Dark gym interiors, orange equipment accents, rubber flooring
- Strength / bodybuilding-forward culture with welcoming mixed community
- Indonesian wall slogan seen: “LAKI MAIN KAKI BUKAN MAIN HATI.” (not used as primary website tagline)
